# v0.5 → v0.6 修改记录

## 导演反馈落实
- 不只排查 Q 版，所有过快切换、闪白和特效都一起减速或删除。
- 画面切换以歌词句子为单位，不再按拍点硬切。
- 节奏到来时让现有画面轻弹、轻推、轻提亮；节拍驱动运动，不驱动快切。
- CG 文字效果避开上半部中央安全禁区，hook 大字放在下三分之一。
- 视频可跟副歌节拍运动；最终副歌的 C/D/E 以句组为界切换，并按强拍轻推/提亮。

## 主要技术改动
- `chorusPoseIndex` 改为歌词 ID → pose 的映射。
- 删除最终副歌最后 16 拍逐拍切图与闪白。
- 喜剧短呼应句共用 Q pose，震屏只保留在主要打断点，气泡弹出也仅用于少数强调句。
- 书页、扫描条、清单雨、光束、震屏减速/减幅。
- 新增可选 A–E 视频层，素材缺失时静帧回退。
- 视频槽卡片继续在审片模式出现，纯净模式隐藏。
