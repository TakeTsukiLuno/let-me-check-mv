# v0.4 → v0.5 修改记录

## 结构与节奏
- 新增 152 BPM / 0.34s 偏移的视觉拍点基座，歌词时间轴保持原样。
- 将四次副歌统一到 8 个核心 pose 的节奏循环；普通副歌每 2 拍切换，终副歌最后 16 拍每拍切换。
- 副歌 2 增加轻量 ✓ 清单雨；副歌 3 加强光束；终副歌增加少量书页与粒子。
- “Wait.” 段改为黑场留白，隐藏人物和装饰层，只保留短句与单点停顿。

## 文字规则
- 删除原本位于人物后方、缺少层级的背景巨字，改用前景 hook / line / sub 三层字。
- 允许有意义的 hook 字短暂覆盖人物（约 0.34 秒），之后立即消失；完整歌词按 pose 的锚点显示。
- 不把“绝不挡脸”作为硬规则，改为避免无意义、长期遮住眼睛、表情或关键手势。
- 目前只有关键 hook 有中文短释义；完整双语字幕 JSON 未随本轮输入提供，暂不补造。

## 视频占位
- 保留审片阶段的视频槽标记：SC-01 为 A，SC-02 为 A/B，SC-15 为 C/D/E。
- 每个视频槽显示特效作用范围选项：视频本体、前景叠加、仅转场。
- 默认打开审片模式以便确认这些标记；按 H 或按钮切换纯净模式时隐藏工程卡片。
- 当前执行包未接入 A–E 1080P 视频，槽位继续以静帧代替；卡片明确提示这一点。
