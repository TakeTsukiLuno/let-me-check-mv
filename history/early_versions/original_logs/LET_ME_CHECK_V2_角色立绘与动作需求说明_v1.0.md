# 《LET ME CHECK? V2》角色立绘与动作需求矩阵 v1.0

**性质：** 绘制前的动作资源计划，不是已完成立绘。  
**依据：** 已通过双语字幕审核的 v0.9 全曲 98 镜头 JSON；音乐时轴 30 FPS。  
**准则：** 正常版负责叙事、行动与自省；Q版负责兴奋状态、夸张喜剧与可复用白边贴纸。

## 1. 用量与结论

| 类别 | 数量 | 说明 |
|---|---:|---|
| 完整镜头 | 98 | 61 正常单独、23 Q单独（含Q背景）、11 同屏、3 无人物 |
| 正常主姿态 | 3 套 | 正面全身、3/4工作、左下探头专用 |
| Q 独立贴纸 | 5 套 | 兴奋、讲解、得意、停格、思维泡弹出 |
| Q 程序衍生 | 2 种 | 缩小欢呼、回声分身，**不单独绘制新母版** |
| 正常表情 | 9 组 | 依统一面部锚点替换，而非新全身图 |
| 正常手势 | 7 组 | 肩、肘、腕固定锚点与袖口一致 |
| Q表情 | 7 组 | 统一脸部位置，口型和眨眼可复用 |
| 分层组 | 15 | 含正常头发、翼尾、衣裙及Q脸部、代码描边 |
| 动画预设 | 20 | 按绝对时间驱动，可复用于多个镜头 |

**注意：** 上述条目不是PNG文件总数。比如正常的3套姿态、9个表情、7个手势可由数个图层组合；绘制前要先验证拆层体系。

## 3. 分层建议

| 分层类型 | 首轮制作必要性 | 原则 |
|---|---|---|
| 身体、脸、双臂、手掌 | P0 | 眼眉口型、指尖动作、手势与躯干可分别控制 |
| 刘海、后发、双翼、龙尾、裙摆 | P1 | 轻量动画可在母版通过后补做；不得改变原轮廓与结构 |
| Q身体、Q五官 | P0 | 白边贴纸伸缩，表情差分必须保持脸部锚点 |
| Q翼尾小摆 | P1 | 不是每张Q都必须复杂绑定 |
| 白色描边/投影 | P0，程序生成 | 用alpha通道生成，正常版弱、Q版强，且放大缩小时厚度稳定 |

**绘制母版前应确认：** 常服结构、银白短发及淡紫发梢、龙角与头饰、浅紫龙翼、前短后长巴洛克裙摆、银白鳞尾及绒毛尾尖；程序动画不得镜像导致左右配饰错位。任何配饰改造都不在本版本范围内。

## 5. 流程与审批

1. **形象核对：** 以既定正常/Q三视图校准八套原画母版的轮廓与配饰。
2. **正常版试制：** 用正常正面、3/4以及5个基础手眼差分完成开头试演。
3. **Q版试制：** 用前四张Q贴纸验证弹跳、文字碰撞和用户打断。
4. **微表演试制：** 验收 `one` 和八音盒段的头部、单指及目光变化。
5. **尾声试制：** 独立测试左下探头、思维泡Q弹出及两次屏幕关机。
6. **补充差分：** 只有确定无法靠复用实现时，才批准新增母版。
7. **全曲覆盖：** 98镜头逐项从“待导演逐镜核对”改为“已确认”；再进入全曲动画与逐帧导出。

## 6. 版本边界与后续调整

- 本版不增加新的服装、发饰、尾饰或任何陌生人设。
- 98镜头结构沿用v0.9；未修改歌词、配乐、双语字幕、用户气泡或歌词演出时间戳。
- 数量是第一轮制作预算，不能作为AI制图一次性出图数量指令。
- Excel中「逐镜矩阵」可以筛选每个素材ID的调用位置；「立绘与差分」列出了该素材被哪些镜头复用。
- **执行前的关键讨论：** 八套姿态母版能否在实际镜头中维持角色高保真？正常龙娘是否需要额外坐姿？如果可以通过工作台遮挡与3/4半身完成，则不要提前增画。
