## 独立制作支线

- **v1.0–v1.1 BG/Console**：三张背景、动作贴图、书页与通信终端的联调；涉及遮挡修正及右侧固定终端。
- **v1.0 N00、v1.2–v1.3 N00**：正常角色预览测试；其中后两版没有找到独立文字日志。
- **Q00 v1**：五套 Q 版母版动作与 36 个使用镜头的素材复用提案；属于当时待审策略。
- **模板 LOCK v1.0**：以 v2.5 为基线冻结待后续整合的演出结构，不是最终成片。
- **CG 工作副本 v2.6 / CG01 v2.8**：CG 占位替换规划，以及开场 S003–S006 四镜头独立联调；不能与全曲同名版本混淆。
