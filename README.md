# LET ME CHECK · 紫晶龙娘 MV

> **公开工程基线：v3.13 FINAL（无音频）**  
> **最新联合修改构建：v3.14.1 · DeepSeek 联合修改版 · 2026-10-23**

《LET ME CHECK》是围绕白龙娘／紫晶龙娘形象创作的非商业同人音乐 MV。本项目保留 98 镜头、双语字幕、1920×1080 / 30fps 的视觉工程与制作沿革。公开仓库不内嵌音乐，不发布私人母带或最终有声成片。

## 项目状态

- 当前工程版本：**v3.14.1 · DeepSeek 联合修改版**。
- 制作基线：v3.13 最终时码与分镜结构；v3.14.1 整合镜头构图/合成修订、代码审查修复和本机 FFmpeg 逐帧输出模块。
- 输出方式：Canvas 按绝对时间逐帧渲染，经本机 Python 桥接程序调用用户电脑上已有的 FFmpeg 直接输出 MP4；不使用实时录制，不依赖 FFmpeg WebAssembly。
- 音源：用户从本地加载 WAV/其他受支持音源；音频不会写入公开工程。

### v3.14.1 本机 FFmpeg 执行包

该构建的执行包已在本地整理，包含自包含 HTML、Python 本地桥接程序、Windows 启动器和使用说明。`.bat` 启动器只随执行包分发，不单独放在仓库根目录。启动器会启动本地服务并打开页面；请保持命令窗口运行。加载本地音源后，使用“逐帧渲染并导出 MP4”。

**发布状态：**本次会话的 GitHub 连接可以提交文本文件，但不提供将本机 ZIP/HTML 二进制直接推送到仓库的上传通道。因此，v3.14.1 执行包目前仍保存在本地归档中；在 `release/` 出现对应 ZIP 之前，不应把它视为已发布的远端二进制包。

执行包的完整镜头修改和历史冲突取舍单独保存在 `history/reviews/LET_ME_CHECK_V2_v3.13-v3.14.1_DeepSeek联合修改记录.md`。
