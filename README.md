## 公开归档的内容（导演确认：仅 ①②⑦）

- **① 工程程序＋历史记录**：`source/` HTML、JavaScript、JSON、40份嵌入显示美术、`history/` 逐版修改记录和审片记录、`tools/` 辅助脚本。

不上传：③ Suno 原始 WAV、④ 正式 MV WAV、⑤ 正式成片 MP4、⑥ 无损 MKV，及任何其他 MP3/FLAC/AAC 音轨。

## 交互工程（**无内嵌音频**）

打开 `source/LET_ME_CHECK_v3.13_交互工程_无内嵌音频.html` 可查看全部 98 镜头、双语字幕与定稿动画。

- 默认没有声音，点击 **播放** 会按时间轴静音播放。
- 如持有私人音源，可在本机通过“可选：本地音频”选择音频文件；不会被嵌入本工程、自动上传至 GitHub 或保存到仓库。
- `source/player_runtime.js` 为同一 HTML 的脚本副本；该副本也移除了内嵌音频初始化。
- `source/embedded_assets/` 是显示用 WebP，`assets/` 是原始美术 PNG。

## 重新组装 GitHub 上传目录

1. 解压旧版 **② 原始绘画素材** 到一个空目录（其附带的根 README/SHA 是旧版，请勿直接提交）。
2. **再解压本次修正的 ① 无音频公开工程** 到同一目录，遇到同名 README、SHA256SUMS、Git 配置文件选择覆盖，以修正版本为准。
3. 将 **⑦ 98镜头审片总览 JPG** 放入 `LET_ME_CHECK_v3.13_FINAL/release/LET_ME_CHECK_98镜头审片总览.jpg`。
4. 在合并目录中运行 `python tools/verify_archive.py`，确认所有所需文件的 SHA-256 校验 PASS。
5. GitHub 已经有提交历史；**先克隆现有仓库** `https://github.com/TakeTsukiLuno/let-me-check-mv`，将组装目录的内容复制到克隆目录后提交，不要初始化新仓库后强制推送覆盖历史。
6. Git 仅提交上述白名单目录；不要将任何音频或视频放入暂存区。Git LFS 已安装，但纯 PNG 文件也可按普通 Git 文件提交（单文件都小于 GitHub 100 MB 限制）。
