# LET ME CHECK · 紫晶龙娘 MV

> **公开工程基线：v3.13 FINAL（无音频）**  
> **最新联合修改构建：v3.14.2 · DeepSeek 联合修改版 · 2026-10-23**

《LET ME CHECK》是围绕白龙娘／紫晶龙娘形象创作的非商业同人音乐 MV。项目保留 98 镜头、双语字幕、1920×1080 / 30fps 的视觉工程与制作沿革。公开仓库不内嵌音乐，不发布私人母带或最终有声成片。

## 项目状态

- 当前工程版本：**v3.14.2 · DeepSeek 联合修改版**。
- 制作基线：v3.13 最终时码与分镜结构；v3.14.1 整合镜头构图/合成修订、代码审查修复和本机 FFmpeg 逐帧输出；v3.14.2 按方案 B 修复输出尾帧，并为 S003、S017 后半加入基于原图裁切的轻微呼吸运动。
- 输出方式：Canvas 按绝对时间逐帧渲染，经本机 Python 桥接程序调用用户电脑上已有的 FFmpeg 直接输出 MP4；不使用实时录制，不依赖 FFmpeg WebAssembly。
- 音源：用户从本地加载 WAV/其他受支持音源；音频不会写入公开工程。

## 协作与署名

### v3.14.2 本机 FFmpeg 执行包

目录：[`LET_ME_CHECK_V2_v3.14.2_DeepSeek联合修改版/`](LET_ME_CHECK_V2_v3.14.2_DeepSeek联合修改版/)

该目录当前包含 `使用说明.md`、`LET_ME_CHECK_V2_v3.14.2_render_local_ffmpeg.py` 和 `启动本地导出.bat`。

**重要：`index.html` 本次按维护决定跳过上传，因此该 GitHub 目录不是完整可运行的执行包。** 完整的自包含 HTML 与上述辅助文件仍在本地执行包 ZIP 中。若要使用本机 FFmpeg 导出，需要完整包中的 `index.html` 与配套程序共同存在于同一目录；`.bat` 启动器只随执行包分发，不单独放在仓库根目录。

启动器会启动本地服务并打开页面；请保持命令窗口运行。加载本地音源后，使用“逐帧渲染并导出 MP4”。

## 定稿时码与技术规格

- 98 镜头，目标 8246 帧，1920×1080，30fps。
- `ONE LAST THING?`：272.621–273.334 秒；S097：272.358–273.334 秒；S098：273.334–274.848 秒。
- v3.14.2 输出参数采用 `-af apad` 与固定 `-t 274.866667`，不使用 `-shortest`；合成帧流测试目标为 8246 帧、274.866667 秒。
- 仅公开无音频工程和制作记录；音乐、母带、最终有声视频不纳入仓库。
